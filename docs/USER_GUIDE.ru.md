# Руководство пользователя
## Guild Control 735 for UWoW Legion

## Перед установкой

**Guild Control рассчитан на использование главой и максимально возможным числом участников гильдии.**

Для общей работы аддон должен быть установлен у главы гильдии и у игроков, чьи сведения вы хотите видеть. Установки только у главы недостаточно: комплекты экипировки, специализации, рейдовые сведения и связи основных и альтернативных персонажей поступают от участников, использующих Guild Control.

Доступные через серверный ладдер сведения Mythic+ и PvP можно просматривать и без установки аддона у каждого участника.

## Установка и первый запуск

### Установка

1. Скачайте установочный ZIP со страницы [Releases](https://github.com/JustAlex888/GuildControl735/releases).
2. Полностью закройте WoW.
3. Распакуйте папку **`GuildControl735`** в каталог **`Interface\AddOns`** вашего клиента UWoW Legion.
4. На экране выбора персонажа откройте список модификаций и убедитесь, что Guild Control включён.

Правильное расположение файла:

```text
Interface\AddOns\GuildControl735\GuildControl735.toc
```

Между папками `AddOns` и `GuildControl735` не должно быть дополнительной папки с названием скачанного архива.

### Как открыть аддон

![Как открыть аддон](images/floating-button.png)

Нажмите **кнопку Guild Control возле мини-карты** или **плавающую кнопку аддона** на экране.

Плавающую кнопку можно перетаскивать и изменять её размер. Разместите её там, где вам удобно открывать окно во время игры.

Дополнительно доступна команда **`/gc735`**.

### Первоначальная настройка гильдии

Главе гильдии нужно открыть вкладку **«Настройки»**, выбрать доверенные звания и нажать **«Сохранить и передать гильдии»**.

Доверенные звания определяют, кто, помимо главы, сможет запрашивать данные через Guild Control. Выбирайте их в соответствии с тем, кому хотите поручить эту работу.

Для передачи обновлённых комплектов участникам необходимо присутствие в игре главы или кого-либо из доверенных участников. После изменения экипировки сохраните текущий комплект в своей визитке заново.

### Обновление аддона

1. Полностью закройте игру.
2. Удалите старую папку **`GuildControl735`** из `Interface\AddOns`.
3. Установите на её место папку из нового установочного архива.

**Папку `WTF` сохраняйте:** в ней находятся настройки и накопленные данные аддона. Для обычного обновления удалять её или сбрасывать настройки не требуется.

### Язык интерфейса

Guild Control поддерживает русский и английский интерфейс. По умолчанию язык выбирается по языку клиента WoW.

Для ручного переключения используйте:

- **`/gc735 language ru`** — русский;
- **`/gc735 language en`** — английский;
- **`/gc735 language auto`** — выбор по языку клиента.

После переключения выполните **`/reload`**.

Выбор языка меняет интерфейс Guild Control. Имена персонажей, названия гильдейских званий, заметки и другие игровые данные сохраняют исходный текст.

## Работа со вкладкой «Общие данные»

![Работа со вкладкой «Общие данные»](images/general-data.png)

### Настройте рабочее окно

Откройте Guild Control и выберите вкладку **«Общие данные»**.

Измените размер окна под свой экран. Откройте меню **«Столбцы»** и оставьте нужные сведения. Чтобы изменить ширину столбца, потяните за разделитель в его заголовке.

Если хотите вернуть исходную ширину столбцов, нажмите **«Сбросить ширину»**. Для просмотра таблицы используйте вертикальную и горизонтальную прокрутку.

### Найдите участников

Введите текст в строку поиска или воспользуйтесь фильтрами:

- **Классы** — отбор по классу персонажа.
- **Звания** — отбор по званию в гильдии.
- **Отсутствие** — отбор по времени отсутствия в игре.
- **Уровень от / до** — нужный диапазон уровней.
- **Только в сети** — показ находящихся в игре участников.
- **Профессии** — поиск персонажей с нужными профессиями.
- **Аддон и специализации** — отбор по наличию соответствующих данных.

Можно применять несколько фильтров одновременно. Например, выбрать нужный класс, задать уровень и включить **«Только в сети»**.

Количество персонажей, прошедших отбор, отображается под таблицей. Чтобы отменить отбор, нажмите **«Сбросить фильтры»**.

### Откройте карточку персонажа

![Откройте карточку персонажа](images/player-card.png)

Нажмите на строку участника. Справа появится его карточка.

Для просмотра подробностей воспользуйтесь кнопками **Mythic+**, **«Рейды»** и **«PvP-активность»**. Доступность сведений зависит от того, какие данные уже получены для выбранного персонажа.

### Обновите сведения

Нажмите **«Обновить состав»**, чтобы обновить стандартные сведения о составе гильдии.

Для получения данных Guild Control нажмите **«Запросить данные»**. Эта возможность доступна главе и участникам доверенных званий. Чтобы прервать текущий запрос, нажмите **«Остановить запрос»**.

### Автоматическое обновление данных — 0.0.103

Доступный глава или доверенный участник автоматически запускает опрос онлайн-персонажей каждые 30 минут. Успешно опрошенные персонажи с актуальной отметкой пропускаются в течение 8 часов. Опрос получает сохранённые комплекты; после изменения экипировки игроку нужно сохранить текущий комплект заново.

Опрос ведёт один клиент. Вход главы или старшего доверенного участника не прерывает уже начатый проход. Доверенные клиенты обмениваются результатами и очередью; если ведущий выходит, доступный доверенный клиент продолжает сбор. Для совместной передачи очереди всем участвующим главам и доверенным клиентам нужна версия 0.0.103.

Один проход ограничен 15 минутами. При достижении лимита очередь очищается; через 30 минут она строится заново из подходящих онлайн-персонажей. Полученные данные и успешные отметки сохраняются. Пропущенные сведения могут быть запрошены повторно.

«Запросить данные» позволяет запросить обновление вручную, обходя восьмичасовой интервал. «Остановить запрос» останавливает местный сбор и откладывает местный автоматический запуск на 30 минут. Рядовые участники получают сохранённые сведения при входе и дополнительно раз в 2 часа, когда доступен источник данных.

### Напомните участникам о визитках

Если нужно попросить участников обновить сведения о своих персонажах, используйте кнопку **«Напомнить о визитках»**.

Через **«Настройки напоминаний»** задайте параметры напоминания. Перед отправкой убедитесь, что сообщение подходит для вашей гильдии.

### Пригласите нового участника

Если у вашего персонажа есть право приглашать игроков:

1. Нажмите **«Пригласить в гильдию»**.
2. Укажите имя приглашаемого персонажа.
3. Подтвердите приглашение в открывшемся окне.

### Работа с отдельным участником

Нажмите **правой кнопкой мыши на участника в таблице**, чтобы открыть контекстное меню. Через него можно изменить звание, отредактировать заметку или исключить персонажа из гильдии. Доступные действия зависят от ваших гильдейских прав.

Для быстрого редактирования заметки можно также **нажать непосредственно на её поле в столбце таблицы**. Откроется окно редактирования выбранной заметки.

### Массовое изменение званий и чистка состава

![Массовое изменение званий и чистка состава](images/mass-actions.png)

Для работы сразу с несколькими персонажами нажмите **«Управление составом гильдии»**.

1. Найдите нужных участников с помощью поиска и фильтров.
2. Отметьте персонажей, к которым хотите применить действие.
3. Выберите массовое изменение звания или исключение из гильдии.
4. Проверьте выбранных участников и подтвердите операцию.

Так можно изменить звания группе персонажей или провести чистку состава без повторения действия для каждого игрока отдельно. Доступность операций определяется вашими гильдейскими правами.

### Прочитайте информацию о гильдии

Нажмите боковую вкладку **«Информация»** или **«Сообщение дня»**. Повторное нажатие на ту же вкладку закрывает панель.

Текст в открывшейся панели можно выделить и скопировать.

## Работа со вкладкой «Моя визитка»

![Работа со вкладкой «Моя визитка»](images/my-card.png)

### Сохраните первый комплект

Откройте вкладку **«Моя визитка»**.

1. Выберите специализацию, в которой играете.
2. Наденьте соответствующую экипировку.
3. Проверьте сведения в блоке **«Текущий комплект»**: специализацию, роль и уровень предметов.
4. Нажмите **«Сохранить текущий комплект»**.

Сохранённый комплект появится в списке **«Опубликованные комплекты»**.

Для передачи сведений гильдии необходимо, чтобы в игре находился глава или участник доверенного звания.

### Добавьте комплект для другой специализации

Если вы играете в нескольких специализациях, сохраните сведения для каждой:

1. Переключитесь на другую специализацию.
2. Наденьте предназначенную для неё экипировку.
3. Нажмите **«Сохранить текущий комплект»**.

Так согильдийцы смогут видеть ваши специализации и соответствующий каждой из них уровень экипировки.

### Обновите или удалите комплект

После изменения экипировки снова выберите нужную специализацию, наденьте актуальный комплект и нажмите **«Сохранить текущий комплект»**. Ранее сохранённые сведения этой специализации обновятся.

**Сохранённые комплекты не обновляются автоматически при смене вещей.**

Если комплект больше не нужен, нажмите **«Удалить»** рядом с ним в списке опубликованных комплектов.

### Добавьте своих персонажей

В блоке **«Мои персонажи»** отображаются персонажи, зарегистрированные аддоном при входе в игру.

Чтобы добавить другого своего персонажа:

1. Включите Guild Control для этого персонажа.
2. Войдите им в игру.
3. Повторите для остальных своих персонажей, состоящих в той же гильдии.

При использовании одного игрового аккаунта на одном компьютере список формируется автоматически. Вручную вписывать имена в блок «Мои персонажи» не требуется.

### Обозначьте основного персонажа

Основного персонажа отмечает глава или участник с правом редактировать **офицерские заметки**.

1. Найдите основного персонажа в составе гильдии.
2. Откройте редактирование его офицерской заметки.
3. Добавьте точную метку **`[GC:MAIN]`**, сохранив нужный текст заметки.
4. Сохраните изменение.

Пример офицерской заметки:

```text
[GC:MAIN]
```

Метка ставится **основному персонажу**. На его альтернативных персонажах повторять её не нужно.

Если среди связанных персонажей отмечено несколько основных, аддон покажет предупреждение. Проверьте их офицерские заметки и оставьте метку только у одного.

### Какие сведения передаёт визитка

Визитка позволяет передать сохранённые специализации и уровень экипировки, сведения о рейдовых достижениях и связи ваших персонажей.

Данные об активности Mythic+ и PvP просматриваются через отдельные разделы аналитики и через визитку не передаются.

## Работа со вкладкой «Аналитика»

![Работа со вкладкой «Аналитика»](images/analytics.png)

Откройте вкладку **«Аналитика»** и выберите направление: **Mythic+**, **«Рейды»** или **«PvP-активности»**.

### Просмотр Mythic+

В разделе **Mythic+** можно сравнить результаты участников: количество прохождений, распределение по уровням ключей, места в ладдере и доступные рейтинги.

1. Откройте **Mythic+**.
2. Найдите интересующих участников через поиск и фильтры.
3. Выберите нужные показатели в меню столбцов.
4. Нажмите на заголовок столбца для сортировки. Повторное нажатие меняет порядок.

Так можно найти участников с опытом прохождения нужных уровней ключей и сравнить их результаты.

### Просмотр рейдового прогресса

1. Откройте раздел **«Рейды»**.
2. Выберите рейд.
3. Укажите сложность.
4. При необходимости ограничьте список участников поиском и фильтром классов.
5. Через **«Столбцы рейда»** оставьте интересующие показатели.

Таблица показывает накопленные сведения о побеждённых боссах по выбранному рейду и сложности.

**Это статистика прохождений персонажа, а не журнал посещаемости гильдейских рейдов.** Она не показывает, с какой группой был побеждён босс, и не определяет количество походов за неделю.

Нажмите **«Обновить»**, чтобы запросить доступные рейдовые данные. Запрос выполняется с учётом доверенных званий и присутствия участников в игре. Если свежий ответ не получен, остаются сохранённые сведения.

### Просмотр PvP-активности

1. Откройте **«PvP-активности»**.
2. Выберите период: **«Неделя»**, **«Сезон»** или **«Прошлый сезон»**.
3. Выберите режим: **1×1**, **2×2**, **RBG**, **SoloQ 2×2** или **«Общая статистика»**.
4. Найдите участников через поиск и фильтры.
5. Через **«Столбцы PvP»** выберите нужные показатели.

В режиме **«Общая статистика»** объединяются количества игр, побед и поражений. Рейтинги и MMR разных режимов не складываются.

**«Неделя» означает недельный период сервера, а не последние семь суток.** После недельного сброса нажмите **«Обновить»** для получения актуальных сведений.

### Фильтры по времени появления и ответа

В аналитике доступны ограничения:

- **«Последний онлайн не более»** — оставляет персонажей, появлявшихся в игре в пределах указанного количества дней.
- **«Последний ответ аддона не более»** — отбирает участников по давности подтверждённого ответа их Guild Control.

Чтобы применить ограничение, включите соответствующую галочку и укажите число дней.

Эти поля отбирают участников. Они не задают период прохождения ключей, убийства боссов или PvP-активности.

### Настройка таблиц и чтение показателей

Используйте меню столбцов, сортировку и прокрутку, чтобы сосредоточиться на нужных результатах. Ширину доступных для изменения столбцов можно настроить перетаскиванием разделителей заголовка.

Наведите курсор на строку или показатель, чтобы прочитать подсказку. **Прочерк не равен нулю:** он может означать, что подтверждённые сведения ещё не получены.

## Настройка доверенных званий

![Настройка доверенных званий](images/settings.png)

**Доверенные звания выбирает глава гильдии.** Они определяют, кто, помимо главы, может запрашивать данные через Guild Control.

### Назначьте доверенные звания

1. Откройте вкладку **«Настройки»**.
2. Нажмите **«Доверенные звания»**.
3. Отметьте звания, участникам которых хотите разрешить запрос данных.
4. Нажмите **«Сохранить и передать гильдии»**.

Глава гильдии всегда имеет доступ к запросам — отключить его нельзя.

Выбор относится ко всему званию. Если хотите предоставить доступ конкретному кругу участников, учитывайте, какие звания они занимают.

### Измените список доверенных званий

Откройте тот же список, добавьте или снимите нужные отметки и снова нажмите **«Сохранить и передать гильдии»**.

Доверенные звания позволяют поддерживать обмен без постоянного присутствия главы. Они **не дают права назначать или снимать ручные баны** на обмен аддона.

## Работа со вкладкой «Сетевая защита»

![Работа со вкладкой «Сетевая защита»](images/network-protection.png)

### Для чего нужна сетевая защита

Guild Control обменивается данными между участниками гильдии. Неисправный или изменённый аддон, а также посторонний инструмент, имитирующий его сообщения, могут создавать чрезмерный поток запросов.

Автоматическая защита временно ограничивает обработку такого обмена. Она защищает работу Guild Control в пределах возможностей аддона, но не является универсальной защитой игры или сервера от DDoS и других сетевых атак.

Автоматическая защита работает у каждого участника. Вкладка позволяет просматривать ограничения, а главе гильдии — дополнительно управлять ручными банами.

### На что смотреть главе гильдии

Если один и тот же персонаж регулярно получает автоматические ограничения, откройте «Сетевую защиту». Посмотрите причину срабатываний и их количество **за последние 24 часа и 10 дней**.

Единичное срабатывание не требует немедленного ручного бана. При повторяющейся активности рекомендуем связаться с игроком и проверить используемую версию аддона. Если проблема продолжается, глава может временно ограничить обмен с этим персонажем вручную на время выяснения причины.

Автоматические срабатывания отражают наблюдения вашего компьютера: это не общий счётчик всех нарушений у всех участников гильдии.

### Найдите персонажа

1. Откройте **«Сетевая защита»**.
2. Найдите участника через поиск или фильтры классов и званий.
3. Если нужного персонажа нет в списке, включите **«Показать всех участников»**.
4. Нажмите на строку персонажа, чтобы увидеть подробности ограничения.

В таблице отображаются состояние обмена, причина ограничения, сведения о нарушениях, наличие ручного бана и оставшееся время.

Автоматические ограничения снимаются самостоятельно.

### Назначьте ручной бан

Эта возможность доступна **только главе гильдии**.

1. Включите **«Действия с нарушителями»**.
2. Отметьте нужных персонажей.
3. Нажмите кнопку **«Действия с нарушителями…»**.
4. Выберите ручной бан на нужный срок.
5. Проверьте список персонажей и подтвердите действие.

Можно отметить нескольких участников и применить действие ко всему выбранному списку.

Кнопка **«Выбрать показанных»** отмечает только строки, которые сейчас видны в таблице. Для очистки выбора нажмите **«Снять выбор»**.

### Снимите ручной бан

1. Включите **«Действия с нарушителями»**.
2. Выберите нужных персонажей.
3. Откройте меню **«Действия с нарушителями…»**.
4. Выберите **«Снять ручной бан»** и подтвердите действие.

Сохранённые ручные ограничения продолжают действовать и тогда, когда глава находится вне игры.

### На кого распространяется бан

Ограничение назначается **отдельному персонажу**. Связь с основным или альтернативными персонажами не переносит бан на остальных.

Если требуется ограничить обмен с несколькими персонажами одного игрока, выберите каждого из них в таблице и примените ручной бан к выбранному списку.

**Ручной бан ограничивает только обмен Guild Control.** Он не исключает персонажа из гильдии и не изменяет его гильдейские права.

## Если возникла ошибка

В **«Настройках»** есть раздел **«Проверка ошибки»**. Он позволяет включить диагностическую запись и собрать дополнительные сведения для разработчика.

Сообщить о проблеме можно и простым описанием: что вы делали, что произошло и какого результата ожидали. Приложите скриншот, если он помогает показать проблему. Однако для выяснения причины программной ошибки особенно полезны сохранённые данные и журналы.

### Какие материалы помогут разработчику

- **`GuildControl735.lua`** — сохранённые данные самого аддона. Файл создаётся при его использовании и записывается на диск при выходе из игры.
- **`!BugGrabber.lua`** — сохранённые Lua-ошибки. Он будет доступен, только если у вас установлен отдельный аддон **BugGrabber** и он сохранил соответствующую ошибку.
- **`taint.log`** — диагностический журнал клиента. Он может содержать нужные сведения, только если запись была включена **до возникновения ошибки**.

Описание помогает понять ситуацию, данные Guild Control дают дополнительный контекст, а отчёт BugGrabber может показать место программного сбоя. Если удаётся воспроизвести проблему с включённой диагностикой и приложить все три файла, у разработчика будет наиболее полный набор материалов для разбора.

### Как записать повторяющуюся ошибку

Если вы знаете, какие действия вызывают проблему:

1. Полностью закройте WoW и снова запустите клиент.
2. Войдите тем персонажем, у которого возникала ошибка.
3. Откройте **«Настройки» → «Проверка ошибки»** и нажмите **«Включить запись»**.
4. Повторите действия, после которых появлялась проблема.
5. После возникновения ошибки нажмите **«Остановить запись»** и проверьте сообщение о её состоянии.
6. Полностью выйдите из игры, чтобы данные записались на диск.
7. Скопируйте доступные файлы для отправки разработчику.

**Диагностическая запись рассчитана на 10 минут, после чего аддон автоматически завершает её.** Если воспроизвели ошибку раньше, остановите запись вручную.

Включайте запись после повторного входа в игру, непосредственно перед проверкой. Если ошибка не повторилась, укажите это в обращении.

### Где находятся файлы

Пути указаны относительно папки вашего клиента WoW.

**Данные Guild Control:**

```text
WTF\Account\<учётная запись>\SavedVariables\GuildControl735.lua
```

**Отчёт BugGrabber, если он установлен:**

```text
WTF\Account\<учётная запись>\SavedVariables\!BugGrabber.lua
```

**Диагностический журнал, если он появился после записи:**

```text
Logs\taint.log
```

Прикладывайте копии файлов. Удалять оригиналы или папку `WTF` не нужно.

### Если ошибку не удалось повторить

Отправьте описание и те материалы, которые есть. BugGrabber мог сохранить первоначальную ошибку даже без включённой диагностической записи.

Включение записи задним числом не восстановит уже произошедшее событие. Отсутствие `taint.log` не мешает обратиться за помощью.

### Как отправить обращение

Нажмите **«Настройки» → «Сообщить об ошибке»**, скопируйте ссылку и откройте её в браузере. На странице GitHub Issues создайте обращение, укажите версию аддона, опишите действия и приложите материалы.

Перед публикацией проверьте файлы и скриншоты: они могут содержать имена персонажей, сведения о гильдии и заметки, которые вы не хотите раскрывать.
